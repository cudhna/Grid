PHUONG PHAP 2: MITRE ATT&CK LAM NEN (THU HEP PHAM VI MALWARE LOADER) + DU LIEU BAO CAO CTI
============================================================================================

0. TAI SAO THAY DOI PHAM VI
---------------------------
Ban dau nap toan bo MITRE ATT&CK vao Neo4j. Ket qua: do thi co 25.639 object dang hieu
luc (697 technique, 730 malware, 176 intrusion-set, 95 tool, 56 campaign, 44 mitigation,
1.758 analytic, 697 detection-strategy...). Do do rat rong so voi pham vi nghien cuu hien
nay, va nhan xet "KHONG phai KG phuc vu CTI ma la mot ban sao cua ATT&CK".

Quyet dinh: pham vi nghien cuu = MALWARE LOADER, va chi giu 2 loai node TACTIC + TECHNIQUE.
Muc tieu la doi thu tu uu tien cua do thi: thay vi "toan bo ATT&CK", thi la
"dinh nghia pham vi loader (o tang ontology) + ket qua gan TTP cua bao cao (o tang du lieu)".

Ket qua cua viec thu hep: 25.639 object -> 179 node lop nen + 28 node lop bao cao.
So node bi loai khoi pham vi: 533 node TTP + toan bo 24.927 object khong phai TTP.


1. MUC TIEU
-----------
Dung mot knowledge graph trong Neo4j voi hai tang:
  - Tang 1 (LOP NEN / ontology): dinh nghia pham vi "malware loader" duoc cat tu chinh
    MITRE ATT&CK. Chi giu x-mitre-tactic va attack-pattern.
  - Tang 2 (LOP BAO CAO / du lieu): ket qua gan TTP cua mot bao cao CTI (report_1.json)
    phu len tren lop nen, luon ghi ro nguon va pham vi.
  - Tang 3 (LOP GRID / du lieu, BO SUNG o muc 12): entity va triple do mo hinh GRID trich
    truc tiep tu van bao procedure cua bao cao. Cung nap qua mot lenh nạp, khong doi lop nen.

Nguyen tac:
  - ATT&CK la ontology goc. Dung lieu tu bao cao chi bo sung, khong thay the.
  - KHONG dung lai ontology rieng cua GRID.
  - Moi node deu tra ve duoc "vi sao duoc giu" (truong keep_reason) => kiem toan duoc.
  - Chay lai nhieu lan khong nhan doi du lieu (dung MERGE + khoa duy nhat).
  - Tang 3 phai tach duoc "model trich" voi "code suy ra", va moi triple phai tro ve
    duoc mot cau trong van bao bao cao (hoac bi gan co, khong duoc xoa).

8. TRUY VAN CYPHER TRONG NEO4J BROWSER
---------------------------------------
Khong chay "tra ve tat ca" vi lop nen van la 179 node, nhung van nen chon dung pham vi.

  -- Kiem tra pham vi --
  // Toan bo node theo pham vi
  MATCH (t:AttackPattern) RETURN t.in_loader_scope AS in_scope, count(*) AS n ORDER BY n DESC

  // Ky thuat loader, theo nhom va ly do duoc giu
  MATCH (t:AttackPattern) WHERE t.in_loader_scope
  RETURN t.keep_reason AS reason, count(*) AS n ORDER BY n DESC

  // Ky thuat chi co trong bao cao, nam ngoai pham vi loader
  MATCH (t:AttackPattern) WHERE t.in_loader_scope = false AND t.layer = 'report'
  RETURN t.id, t.name, t.keep_reason

  -- Ket qua gan TTP cua bao cao --
  // Technique bao cao quan sat + tactic tuong ung
  MATCH (r:Report {id:'report_1'})-[:OBSERVES]->(t)-[:PART_OF]->(k) RETURN r, t, k

  // Phan bo theo tactic (cua lop bao cao)
  MATCH (r:Report {id:'report_1'})-[:OBSERVES]->(t)-[:PART_OF]->(k)
  RETURN k.name AS tactic, count(*) AS n ORDER BY n DESC

  // Chi phan trong pham vi loader
  MATCH (r:Report {id:'report_1'})-[:OBSERVES]->(t) WHERE t.in_loader_scope
  RETURN t.id, t.name

  // Cay sub-technique cua mot technique
  MATCH (p:AttackPattern)-[:SUBTECHNIQUE_OF*1..2]->(c:AttackPattern {id:'T1059'})
  RETURN p.id, p.name

  -- Kiem tra chat luong --
  // Technique co ten khac ten chuan cua ATT&CK (lay tu flags.json)
  // Node lop bao bao chua co node nen nao noi toi (dang so)
  MATCH (a)-[e]->(b) WHERE e.layer = 'report' AND NOT a:Report RETURN a, e, b

Meo: trong tab Graph, chon caption cua tung loai node la "name" de de doc.
